# Movie-Review-Sentiment-Analysis
A machine learning web application that predicts whether a movie review is Positive or Negative.

🛠️ Technologies Used
Python
Streamlit
Scikit-learn
TF-IDF
Logistic Regression

✨ Features
Predict positive or negative sentiment.
Display prediction confidence.
Show a visual confidence bar.
Clear reviews and analyze new ones.
Simple and user-friendly interface.

📊 Dataset
Used the IMDb Movie Reviews Dataset, containing 50,000 reviews.

📈 Model Accuracy
Approximately 88.3% test accuracy.
